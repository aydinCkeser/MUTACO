# Analytic experiment declarations

The handwritten and frozen-GP JSON files select the forward map, target, budget, noise model, optimizer and assessment settings used by the [analytic experiments](../README.md). The noisy-cohort declarations specify a target bank and repeated inversions. The [benchmark campaigns](benchmark_campaigns/) declare distinct comparator settings, including separately versioned original and corrected Prompt 5D configurations. Preserve the supplied campaign identities when interpreting their saved results.

The two smoke TOML files are retained model declarations. The tracked experiment defaults use JSON. Their existing names and contents are retained for readers with earlier configurations.
