# Frozen graph target inputs

[Paper120 v3](paper120_v3/) holds 120 measured response records for the graph inversion benchmark. The [manifest](paper120_v3/manifest.json) records the selected indices and the scientific content and target IDs. Each JSON file, including the manifest, has an adjacent SHA-256 sidecar. The records preserve the physical parameter/response order, realization provenance and the exact target simulator configuration used at generation.

These are inputs to inference and held-out assessment. Reading or hashing them performs no physical evaluations. The [cohort specification](../configs/paper120_v3_cohort_spec.json) and [physical configuration](../configs/paper120_v3_target_config.json) explain how the targets were generated. Each record identifies the parameter declaration by its original Git revision and path. For Paper120 v3, `git show b43296ee24392df104874044888f770fc61947b6:experiments/graph_inversion/target_declarations/paper_120_v3_theta_ledger.json` reads those original bytes. The [currently tracked declarations](../target_declarations/) serve other cohorts. Use the stored records for verification. Sealed campaign and validation records keep the original `data/cohorts/paper120_v3` identifier. Current readers open its contents here.
