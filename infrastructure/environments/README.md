# Numerical environment records

The requirements files record the dependencies used by the named local and TRUBA workflows. The corresponding lock JSON records exact library versions. The macOS ARM64 qualification records the observed platform, package versions, test outcomes and scope of that engineering check. Read its recorded status before drawing a numerical conclusion on another platform.

Use the [local setup guide](../local/README.md) to select the matching interpreter and the [TRUBA guide](../truba/README.md) to locate the separate qualified compute procedure. These records themselves execute no code. Preserved paths within old reports and the pinned reference harness continue to resolve through the legacy environment directory.
