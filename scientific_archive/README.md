# Scientific archive

Use [current scientific results](../results/README.md) when interpreting the manuscript. A record belongs here when its investigation has been superseded or when it documents the project at an earlier revision. Some failed intermediate runs remain alongside current results because they explain a repair or a cohort exclusion.

| Area | What a reader can recover |
| --- | --- |
| [Superseded results](superseded_results/README.md) | Earlier comparison and qualification packages, including their original outcomes, counters and manifests. |
| [Validation history](validation_history/README.md) | Historical acceptance reports, terminal-lineage evidence and the scope of same-environment regression. |
| [Project records](project_records/README.md) | Reviewed state, schema, handoffs and original compact benchmark catalogs. |

Historical Git revisions and relative paths identify particular implementations and data. Use the [migration map](../docs/decisions/repository_migration_map.md) for current lookup and the [documentation authority](../docs/DOCUMENTATION_AUTHORITY.md) for present scientific decisions.
