# Project coordination and authority

- [state.toml](state.toml): material state plus dated historical milestones.
  Old authorization/status fields describe their own task; they are not standing
  permission for execution.
- [scientific_registry.toml](scientific_registry.toml): index of normative,
  candidate, forensic and historical contracts; check the classification.
- [experiment_registry.toml](experiment_registry.toml): experiment/evidence
  lineage; follow referenced manifests for exact provenance.
- [state.schema.json](state.schema.json): state metadata schema.

The original handoff, prompt, and continuation documents are in the private historical archive. They are not current execution authorization or a
substitute for active state, scientific scope and the user's instructions.
Registries and snapshots remain in place to preserve references.

Start scientific reading at the [core map](../src/mutaco/README.md), research
navigation at the [catalog](../experiments/README.md), and results at the
[evidence index](../benchmarks/README.md). Those routes require no prompt history.
