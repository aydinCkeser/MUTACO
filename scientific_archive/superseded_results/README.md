# Superseded experiments and engineering records

These manifests and diagnostics describe work outside the primary Paper-120
comparison. The earlier composite Monte Carlo NEI qualification recorded
failed and cancelled attempts, a factorization diagnostic, and a
prequalification rescue. The scalar qLogNEI population in the manuscript
uses a different method. Compare the saved statuses and call accounting
within the original attempt before interpreting an error or a recovery.

The historical graph engineering records include the all-method smoke
run and identity checks. They retain their
inputs, source revisions, statuses and original cohort semantics. They do not
extend the accepted B40/B100 population. The [current results index](../../results/README.md)
leads to the accepted population and to supporting precursors which the
current evidence still cites, including the incomplete v1 held-out attempt
used in the v2 record.

Read these records in place. The old package paths continue to resolve from
a symlink-capable checkout. Reproducing a physical evaluation, fitting a model
or submitting an experiment requires a separate execution scope.
