# Physical graph simulator

The [graph-oscillator package](graph-simulator/README.md) evaluates a vector of physical graph parameters at controlled bias conditions and returns ordered response statistics. It supplies the concrete forward map for [graph-forward characterization](../experiments/graph_forward/README.md) and [graph inversion](../experiments/graph_inversion/README.md). The simulator-independent search algorithm consumes the public simulator protocol.

Start with [parameter and response profiles](graph-simulator/src/mutaco_graph/profiles.py) for axis order and bounds. [The scientific implementation](graph-simulator/src/mutaco_graph/scientific.py) integrates overdamped dynamics with named disorder and noise streams. The [retained model](graph-simulator/src/mutaco_graph/retained.py) preserves a different historical physical profile. [Parity code](graph-simulator/src/mutaco_graph/parity.py) compares defined calculations at matched inputs; a stored inversion replay cannot establish physical kernel parity.

The independent distribution is built from [graph-simulator/pyproject.toml](graph-simulator/pyproject.toml) and imported as `mutaco_graph`. Importing the package loads definitions. Evaluating the simulator and running its parity or profiling programs perform physical computations. See the [local installation guide](../infrastructure/local/README.md) for dependency captures and platform scope. The [analytic forward models](../experiments/analytic_target_matching/forward_models/README.md) serve controlled target-matching experiments through a separate install, `mutaco_analytic`.
